# D2

Declarative diagram language for architecture, flows and nested containers, with automatic layout. Rendered offline to SVG (icon set {{AWS_ICONS_VERSION}} applies to PlantUML only).

## When to use

- Quick box-and-arrow architecture or flow diagrams with automatic layout.
- Nested containers (systems inside networks inside regions) without manual positioning.
- Simple sequence diagrams (`shape: sequence_diagram`) and SQL tables (`shape: sql_table`).
- For AWS service icons use the PlantUML-based guides (`aws-architecture`); D2 here cannot
  load icon images.

## Building blocks

- Shapes are declared by name: `api`, with a label `api: Orders API`.
- Connections: `a -> b`, `a <- b`, `a <-> b`, `a -- b`, with labels `a -> b: calls`.
- Containers nest with dots or blocks: `cloud.vpc.api` or `cloud: { vpc: { api } }`.
- Shape kinds: `db.shape: cylinder`, `queue.shape: queue`, `user.shape: person`,
  `doc.shape: page`, plus `rectangle`, `oval`, `hexagon`, `cloud`, `diamond`.
- Styles: `api.style.fill: "#e8f0fe"`, `api.style.stroke-dash: 3`, `direction: right`.
- Special shapes: `shape: sql_table` (columns as fields), `shape: sequence_diagram`.
- Output: SVG only in this server (the PNG converter for D2 is not bundled).

## Refused here (and what to use instead)

| Refused | Why | Use instead |
|---|---|---|
| `icon:` pointing at an `http(s)` address | Remote fetch | No icon, a `shape:` kind, or PlantUML with `AWSPuml/` icons |
| Imports (`@file`, `...@file`) of an `http(s)` address | Remote fetch | Keep the whole diagram in one source |
| `output=png` for D2 | Not supported by the bundled engine | `output=svg` |

## Examples

Nested containers with automatic layout:

```hermetic-example format=d2 output=svg
direction: right
user: Customer {shape: person}
cloud: Cloud {
  vpc: VPC {
    api: Orders API
    db: Orders DB {shape: cylinder}
    api -> db: SQL
  }
  queue: Events {shape: queue}
}
user -> cloud.vpc.api: HTTPS
cloud.vpc.api -> cloud.queue: order.created
```

SQL tables with a relation:

```hermetic-example format=d2 output=svg
orders: {
  shape: sql_table
  id: uuid {constraint: primary_key}
  customer_id: uuid {constraint: foreign_key}
  total: decimal
}
customers: {
  shape: sql_table
  id: uuid {constraint: primary_key}
  name: text
}
orders.customer_id -> customers.id
```
